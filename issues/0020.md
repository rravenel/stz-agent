## Description

The QuickJS snapshot/restore spike (#0011) passed in local Node only. Run the same checks inside Lambda: restore a snapshot in a cold Lambda invocation, resolve the pending fetch, and measure restore time with the 2 GB Prime memory setting.

## Long Description

- Snapshot in one invocation, store it in S3, restore in a second (cold) invocation; report restore time cold and warm.

## Run-book

1. Add `"spike_s1": "on"` to the `context` in `cdk.json`, run `scripts/deploy.sh`, then undo the edit.
2. `aws lambda invoke --function-name StzAgent-<env>-s1-spike --cli-binary-format raw-in-base64-out --payload '{"mode":"snapshot"}' out.json --profile stz-dev`
3. Force a cold start with `aws lambda update-function-configuration --function-name … --description "cold 1"`, wait for it, then invoke `{"mode":"restore"}` (cold) and again (warm).
