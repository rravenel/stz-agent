## Description

Follow-ups from the #0021 review.

- **Empty replies:** the Anthropic and OpenAI adapters can return no usable content. From reading the code, the harness then drops the message and sends the same billed call again (fixed for Bedrock only; not reproduced for these two). Guard once in `onModelResponse`.
- **Errors:** on a non-2xx response the body is ignored, so "Access denied" shows as "request failed (HTTP 403)".

## Relation

Follow-up to #0021.

## Resolution notes

Reviewed 2026-11-24 by an independent review subagent: APPROVE. The empty-reply loop was reproduced for the Anthropic adapter (the new test fails on the old code). Low notes: the first 500 characters of an error body also enter the model context; an empty reply's usage is not logged; a non-2xx REPL fetch still hides its status and body (pre-existing).
