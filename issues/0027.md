## Description

Owner issue (lockfile). #0009 adds the `client/` TS package with devDependencies (`typescript`, `esbuild`, `@types/node`, same ranges as `functions/`). `scripts/setup.sh` refuses any TS package without a `package-lock.json`, and only a person may create lockfiles.

## Steps (person)

After #0009 is merged to `main`:

```sh
cd ~/Developer/git/stz-agent
scripts/lock.sh             # creates client/package-lock.json (and re-checks the others)
scripts/setup.sh            # installs client/node_modules
scripts/check.sh            # must end CHECK OK, with typecheck-client / build-client / test-client lines
git add client/package-lock.json
git commit -m "#0027 Lock client/ dependencies"
git push origin main
```

## What to paste back

In the Agora task thread: the last lines of `scripts/check.sh` and the commit hash. Then @mention the orchestrator (`@pm`).

## Expected behavior

Done when: `client/package-lock.json` is on `main` and `scripts/setup.sh` + `scripts/check.sh` succeed.
