## Description

Agent instructions live in two files: `CLAUDE.md` (the full guide) and `AGENTS.md` (a stub that defers to it). The owner wants a single file, `AGENTS.md`, which every agent (Codex, OpenCode, Claude Code) reads. Depends on #0018, whose doc changes this branch builds on.

## Fix

- `AGENTS.md` now holds all of the old `CLAUDE.md` content plus its own must-knows. The commands section now leads with `scripts/`; raw `pytest`/`cdk` commands are listed as a people-only reference, which resolves the old contradiction between "always activate the venv and run `pytest`" and "only use the scripts". It also mentions the `I` milestone and `infra/` branches.
- `CLAUDE.md` is one line, `@AGENTS.md`. Claude Code reads `CLAUDE.md` and expands the import, so it gets the same instructions without a second copy.
- `README.md`: the demo deploy and the "Useful commands" list now point at `scripts/deploy.sh` and the pinned CLI, not a global `cdk` (a follow-up from the #0018 review).
- `issues/Issues.md`: references to `CLAUDE.md` now point at `AGENTS.md`.

## Decisions taken without the owner

- **Kept a one-line `CLAUDE.md` import** rather than deleting the file. Claude Code loads `CLAUDE.md`, not `AGENTS.md`, so deleting it would leave Claude agents with no project instructions. **Wants owner feedback:** delete the stub if your Claude Code setup reads `AGENTS.md` directly.
