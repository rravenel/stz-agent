## Description

Success criterion 3 needs `scripts/cost-report.ts`: pull the CloudWatch `REPORT` lines for all three functions over a time window and compare their billed GB-seconds with what Prime alone would have cost staying up for the whole wall-clock time.

## Long Description

Spec §1 (criterion 3), §8:
- Input: stack env name and a time window (or "the last N minutes").
- Read `REPORT` lines via CloudWatch Logs (`FilterLogEvents`) for Doorman, Prime and Com; sum billed duration × memory per function.
- Print a small table: per-function invocations, billed GB-s, cost; the counterfactual "Prime up for the whole window" GB-s; and the ratio.
- Parse logic is a pure function with unit tests on captured `REPORT` lines (no AWS in tests).
- Lives in `scripts/cost-report.ts`, built and tested through the `functions/` workspace or its own package; keep it reachable from `scripts/test.sh ts`.
- **Needs owner:** running it against real logs requires AWS credentials.

## Plan

Files: `scripts/cost-report.ts`, `scripts/cost-report.test.ts`, `functions/package.json` (test glob), `functions/tsconfig.json` (include). Don't touch `stz_agent/` or `app.py` (#0003 is in flight there).

1. **Function and log-group names.** #0003 sets explicit names `StzAgent-<env>-doorman|prime|com`, so log groups are `/aws/lambda/StzAgent-<env>-<fn>`. Derive them from `--env`; no stack-output lookup. Allow `--log-group-prefix` to override for odd setups.
2. **Pure parser** `parseReport(message: string, timestampMs: number): ReportLine | null`. Match `REPORT RequestId: <id>\tDuration: <x> ms\tBilled Duration: <n> ms\tMemory Size: <m> MB\tMax Memory Used: <k> MB` with optional `\tInit Duration: <y> ms` (tabs or spaces; extra trailing fields such as XRAY ignored). Return `{requestId, durationMs, billedMs, memoryMb, maxMemoryMb, initMs?, endMs: timestampMs, startMs: timestampMs - durationMs - (initMs ?? 0)}`. Non-REPORT lines → `null`.
   - Billing: use `Billed Duration` as is. Since Aug 2025 AWS bills the init phase and folds it into `Billed Duration`; record `initMs` separately for display but don't add it again.
3. **Pure summarizer** `summarize(byFn: Record<"doorman"|"prime"|"com", ReportLine[]>, opts: {pricePerGbSecond, pricePerRequest, primeMemoryMb})`:
   - Per function: invocations, billed GB-s = Σ billedMs/1000 × memoryMb/1024, cost = GB-s × price + invocations × request price.
   - **Wall clock** = activity span: earliest `startMs` to latest `endMs` across all three. (Also print the requested window.)
   - Counterfactual = Prime's memory (from its REPORT lines, else `primeMemoryMb` 2048) × wall clock seconds, plus its cost.
   - Ratio = actual total cost / counterfactual cost, and Prime billed seconds / wall-clock seconds.
   - Defaults: x86_64 us-west-2, `$0.0000166667`/GB-s, `$0.20`/1M requests; constants at the top, overridable with `--price-gb-s`.
4. **Formatter** `formatTable(summary): string`: aligned plain-text table, one row per function, a total row, then the counterfactual and ratio lines. Pure, so it's testable.
5. **CLI** (only runs when executed directly: `if (process.argv[1] === fileURLToPath(import.meta.url))`): `node scripts/cost-report.ts --env <name> (--since 30m | --start ISO --end ISO) [--profile stz-dev] [--region us-west-2]`. For each fn: `execFile("aws", ["logs","filter-log-events","--log-group-name",g,"--start-time",ms,"--end-time",ms,"--filter-pattern","\"REPORT RequestId\"","--output","json","--profile",p,"--region",r])`, parse `events[].{message,timestamp}`. A missing log group (`ResourceNotFoundException`) counts as zero invocations with a warning, not a crash. Use `node:util` `parseArgs`. Node builtins only; must run under Node's type stripping (`erasableSyntaxOnly`: no enums or parameter properties).
6. **Wire into the workspace.** `functions/package.json` `test`: append `"../scripts/*.test.ts"`. `functions/tsconfig.json` `include`: add `"../scripts/*.ts"`. Usage line in the file header: `node scripts/cost-report.ts --env rene --since 30m` (Node ≥ 22.18).
7. **Tests** (`scripts/cost-report.test.ts`, `node:test`, no AWS): parse a captured REPORT line with and without `Init Duration`, with XRAY suffix, and a non-REPORT line → null; summarize a hand-built set (e.g. Prime 2048 MB 3×2 s, Com 128 MB 1×90 s over a 100 s span) and assert GB-s, counterfactual and ratio to 6 decimals; argument parsing of `--since 30m` → window ms; formatter contains each function row. The CLI path that shells out is not unit-tested: mock nothing, keep it thin.
8. **Verify**: with the exports above, `scripts/check.sh` → `CHECK OK`, and `test-functions` count goes up by the new tests (21 → 21+N). Also `node scripts/cost-report.ts --help` exits 0. Paste both into `## Verification`.
