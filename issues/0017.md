## Run-book

1. Deploy (`scripts/deploy.sh`; the demo stack is `scripts/deploy.sh demo --yes`, **people only**) and export `STZ_API_TOKEN` as in #0023.
2. Put the script below at `s3://<BucketName>/mock/script.json`. The model step index counts assistant messages already in the conversation, so prefix one zero-delay filler step per existing assistant message (or use a fresh stack).
3. `caffeinate -i node scripts/e2e.ts --env <env>`, then `node scripts/cost-report.ts --env <env> --start … --end … --profile stz-dev`.
4. Delete `mock/script.json`.
