## Description

Com is a stub. It must accept `http.request` messages within its deadline window, stream each response body to S3, and send a terminal `http.response` to Prime, with the `mock` and `none` auth modes working first.

## Long Description

Spec §6, §8; protocol §7.2, §8:
- Uses the comms worker (#0005). On `http.request`: apply the deadline rule (accept only if `now + timeout_s < run_start + 15 min − margin`, else leave it unacked); otherwise ack, delete, dedupe by `request_id`, read the request body from S3, start the request.
- Stream the response to `bodies/<request_id>.res` with `@aws-sdk/lib-storage` `Upload`; never buffer the whole body.
- Terminal `http.response` on success, HTTP error or timeout (per-request `timeout_s`, default 10 min).
- Auth modes: `none`, `mock` (sleep N s, return a scripted Messages-API response; scripts configurable), and `mock://slow?seconds=N&body=...` URLs. Then `anthropic` and `openai` (keys from Secrets Manager, cached per run). `bedrock` (SigV4) is optional for the hackathon; if skipped, file it as a follow-up.
- Exit when nothing is in flight, the unacked set is empty and a final poll is empty.
- Unit tests with the in-memory fake: deadline rule, dedupe, mock model script, slow URL, terminal response on timeout.
