## Description

Owner issue (dependency declaration). #0025 signs Bedrock requests with `@smithy/signature-v4`, which is in `functions/node_modules` only as a transitive dependency of the AWS SDK clients (#0024). Declare it so a future SDK bump can't silently remove it. It is a runtime dependency: esbuild bundles `@smithy/*` into Com (only `@aws-sdk/*` is external).

## Steps (person)

After #0025 is merged to `main`:

```sh
cd ~/Developer/git/stz-agent
npm --prefix functions install -w com @smithy/signature-v4@^5.7.5
scripts/lock.sh
scripts/check.sh            # must end CHECK OK
git add functions/com/package.json functions/package-lock.json
git commit -m "#0028 Declare @smithy/signature-v4 for Com"
git push origin main
```

## What to paste back

In the Agora task thread: the last lines of `scripts/check.sh` and the commit hash. Then @mention the orchestrator (`@pm`).

## Expected behavior

Done when: `functions/com/package.json` lists `@smithy/signature-v4`, the lockfile is updated on `main`, and `scripts/check.sh` → `CHECK OK`.
