## Description

Prime needs adapters that translate its internal turn format to and from each provider's wire format, chosen by environment variable. The mock model speaks the Anthropic format, so that adapter comes first.

## Long Description

Spec §5.3; open-questions "Decided":
- `functions/prime/models/`: internal turn type (messages, tool calls with `tool_call_id`, tool results), and one adapter per provider: `toRequest(turn) → {url, headers, body, auth}` and `fromResponse(bytes) → turn`.
- Order: **Anthropic Messages API** (also used by `mock`), then **OpenAI Chat Completions** (base URL + model name), then **Bedrock** (optional for the hackathon; file a follow-up if skipped).
- The single tool exposed to the model is `repl(code)`.
- Provider from env (`MODEL_PROVIDER`, `MODEL_NAME`, `OPENAI_BASE_URL`); no keys in Prime (Com adds auth).
- Unit tests on recorded request/response fixtures for each implemented adapter, including a tool-call round trip.

## Expected behavior

Done when: `scripts/check.sh` → `CHECK OK` with adapter fixture tests counted.

- **Carry into #0013 (the agent loop), not blocking:**
  1. **Don't eval `_invalid_json` input.** The adapter keeps the raw argument text as `code`; the loop should return a tool error ("arguments were not valid JSON: …") rather than run that text as JavaScript.
  2. **Empty text blocks:** Anthropic rejects empty `text` blocks and empty assistant `content`. Drop empty text in `toWire` or before building the request.
  3. **OpenAI `max_tokens`:** newer OpenAI models want `max_completion_tokens`; most compatible servers still take `max_tokens`. Fine for the hackathon; worth a config switch if we use OpenAI's own API.

## Root cause

Prime had no way to talk to a model provider.

## Fix

`functions/prime/src/models/`: `turn.ts` (neutral turn format, `repl` tool definition, `ModelAdapter`), `anthropic.ts`, `openai.ts` and `config.ts` (`adapterFromEnv`). The adapters build the `http.request` that Prime sends to Com, with no keys, and parse response bodies into `ModelReply`.
