## Description

Owner issue (package install). `functions/node_modules` has no `@aws-sdk/*`, and agents can't install packages. #0005 step 4 (real SQS/Lambda ports) is blocked on it, and #0006 (S3 streaming, Secrets Manager) and #0007 (S3 log reads) will need it. The Lambda runtime ships SDK v3 and `functions/build.mjs` keeps `@aws-sdk/*` external, so these are for types and local tests.

## Steps (person)

```sh
cd ~/Developer/git/stz-agent
npm --prefix functions install -w shared -D @aws-sdk/client-sqs @aws-sdk/client-lambda @aws-sdk/client-s3 @aws-sdk/lib-storage @aws-sdk/client-secrets-manager
scripts/lock.sh
scripts/check.sh            # must end CHECK OK
git add functions/shared/package.json functions/package-lock.json
git commit -m "#0024 Add AWS SDK v3 packages for types and tests"
git push origin main
```
